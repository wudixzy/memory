# 研究进展整理与阶段复盘

2026-09-13。本文件整理截至 ACE 五任务真实批次及其 review 的状态，不启动新实验。
逐样本证据与原始运行记录以各批次报告为准；本次没有重新运行模型或改写历史产物。

## 1. 当前结论

**工程接入已有明显进展，但科研结果尚未达到验证 A+B 猜想的目标。**

- **A 有具体案例证据**：包括记忆来源/时序错记、缺少支持的条件概括，以及更新流程中的条目过滤。也有合理提取、条件修补和健康复用的反向证据。尚未估计这些问题的发生率或普遍性。
- **B 尚无有说服力的有害因果证据**：AutoManual 三个限定干预筛选没有支持目标效应；ACE 优惠候选在来源分析后停止，目标分支未运行。两者不能混为同一种阴性结果。
- **A+B 有害反馈链、长期锁定和恢复差距均未得到确认**。任务成功、记忆被引用或旧技能保留，单独都不足以证明这些结论。

## 2. 问题定义保持完整

**A：从一条或多条轨迹中提取可靠的多条记忆，并维护整个集合。**
检查事实、来源、时序、适用条件、概括强度、信息取舍、互补/遗漏/冲突，
以及后续新增、修订、合并、删除和保留是否合理。A 不以出现任务失败或 B 为前提。

**B：记忆如何影响行动、证据获取、探索，以及更优策略的发现、比较和采用。**
包括错误经验限制纠错，也包括正确、有用的经验使 Agent 停留在次优路径。
不要求记忆先写出“不要探索”；正确规则和熟悉流程同样可能影响行为。
但少探索、局部顺序变化或引用记忆，也不自动构成有害作用。

## 4. A 的证据应如何使用

|证据类型|具体案例|解释边界|
|---|---|---|
|已写入的事实/来源错误|灯任务成功时序错记；Book M1 将自行加入的 desk_1 归为初始观察，并写入 rule_0/6|支持局部记忆可靠性问题；不能自动推出后续行为伤害|
|条件或验证范围缺少支持|开门后变换成功被概括为必须开门；加热分支 M3 扩大 rule_8 验证范围|成功轨迹不证明必要性；区分未获验证与已经证伪|
|更新流程过滤|ACE 三项候选建议因 section 名不符被原生 Curator 校验跳过|模型提出了建议，流程没有保存；属于实现/协议层发现，不能说模型未能提取|
|尚需限定的语义线索|ACE 日期规则绝对排除邮件时间来源，未保留任务明确“今天收到邮件”的条件|优先可靠系统时间本身合理；尚未证明这条规则造成错误|
|健康更新和复用|开门条件合理修补；待验证效率建议；支付核验、卡有效期和资金条件保留；优惠量化比较|必须和问题案例一起报告，不以未出现故障为由排除|

Reflector 的误述、Curator 的提案、实际持久化条目分别记录。
静态示例归属混淆和被首代码块解析裁掉的虚构续写，不能直接算成已进入长期记忆的污染。

## 5. B 为什么还没有得到支持

1. **早期干预范围较窄且知识冗余。** 规则、历史、技能和 helper 可能提供替代路径；局部屏蔽不等于移除相关经验。阴性结果只约束实际干预的边际作用。
2. **部分指标离真正的改善较远。** 早拿书未必降低总成本；已经成功也不说明轨迹最优。必须结合实际路径、信息和成本逐样本分析。
3. **优惠候选改变了最佳选择，却没有改变适当的比较策略。** 新旧码谁便宜虽反转，来源和目标都适合“检查两者、比较后选择”，指令本身也要求比较。来源任务实际形成的是条件化知识，而非省略检查的流程。
4. **候选不能只按限制性文字筛选。** 没有明确错误规则不等于没有 B；熟悉策略引起的搜索顺序固化、过早停止或遗漏替代方案同样值得研究。当前优惠批次按登记条件停止，不把这条停止判断推广为一般准入标准。

因此目前不能断言“B 不存在”，也不能认定“只是模型太强”或“benchmark 不行”。
现有样本尚未提供足够可解释的记忆→行为/证据→损失因果链。
后续若继续，应论证来源经验在目标条件下如何可能限制纠错或改善，
再在同一目标任务上比较 intact 与范围明确的干预；允许集合、关键步或临时移除，
不局限于单规则。不能人工注入错误记忆或改变原生任务来保证阳性。

## 6. 最近批次的成本、兼容性与证据核查

ACE 五任务使用 94 次真实生成请求：84 Generator、5 Reflector、5 Curator；
输入 1,297,313 tokens，其中缓存 1,031,552；输出 190,011。
本地估算 **USD 0.313930812**，embedding 为 0，provider 金额为 null；无自动重试或补跑。
USD 6 批次上限的剩余额度不自动授权新的实验。

本次 review 核对到四处跨任务 memory 继承一致、调用/token 汇总一致，
停止记录引用的 215 个源文件哈希匹配。17 次达到 8192 输出上限的调用均来自 Generator，
不来自 Reflector/Curator。该兼容性限制需要保留，任务成功不能证明其没有影响。
请求/返回模型别名一致也不保证与历史 ALFWorld 批次的后端权重相同。

源码采用固定官方版本并保存声明 patch；模型替换、DashScope embedding 替换、
受限 Python、AutoManual 专属 won 反馈及 ACE 原生 ADD-only/终段输出边界均以各接入报告为准。
这些结果不声称完全复现论文原模型成绩，也不构成形式化隔离证明。
